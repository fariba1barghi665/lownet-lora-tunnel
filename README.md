# LoRa-Based Communication Tunnel for LowNet

This project presents the design and implementation of a LoRa-based communication tunnel for educational LowNet subnetworks using ESP32, ESP-NOW, and LoRa TTGO boards.

The system enables communication between different university buildings without using WiFi infrastructure or the Internet.

## Features

- ESP-NOW local communication
- LoRa inter-subnet communication
- Transparent packet forwarding
- Time synchronization
- NS-3 simulation
- Real hardware implementation
- Low-level LoRa driver integration

## Technologies

- ESP32
- ESP-IDF
- LoRa SX1276
- ESP-NOW
- FreeRTOS
- NS-3
